# MJ-PRO-BOT (Node.js)

## Requirements
- Meta Developer account
- WhatsApp Cloud API enabled (App)
- Phone Number ID + Permanent Access Token
- Public HTTPS URL for webhook (Render/Railway/Fly/VPS)

## Env
Copy `.env.example` to `.env` and fill:
- VERIFY_TOKEN
- WHATSAPP_TOKEN
- PHONE_NUMBER_ID

## Run locally
```bash
npm i
npm start
